# 🎟️ Movie Ticket Booking System

A desktop-based **Movie Ticket Booking Application** built using **Java Swing** and **Oracle Database**.

This application allows users to browse movie shows, view details, and book tickets with a clean and interactive GUI.

---

## ✨ Features

- **Home Screen** with movie posters (clickable)
- **Shows Page** – Displays all available movies with posters, title, price, description, and timing
- **Book Tickets** – Simple booking form (Name, Email, Phone, Number of Tickets)
- **My Bookings** – View all previous bookings in a table
- **Navigation** via top menu labels (Home, Shows, Book Tickets, Bookings, Help)
- **Oracle Database** integration for shows and bookings
- Responsive image loading and error handling

---

## 🛠️ Technologies Used

- **Java** (Swing + AWT)
- **Oracle Database** (JDBC)
- **JDBC Driver** (`oracle.jdbc.driver.OracleDriver`)
- **javax.imageio** for image handling

---

## 📋 Database Setup

### 1. Create Database Schema

Run the following SQL scripts in your Oracle Database:

```sql
-- Create SHOWS table
CREATE TABLE SHOWS (
    SID NUMBER PRIMARY KEY,
    TITLE VARCHAR2(100),
    PRICE NUMBER(10,2),
    DESCRIPTION VARCHAR2(500),
    IMAGE_ID VARCHAR2(255)
);

-- Create SHOWTIME table
CREATE TABLE SHOWTIME (
    SID NUMBER,
    TIMING VARCHAR2(50),
    FOREIGN KEY (SID) REFERENCES SHOWS(SID)
);

-- Create BOOKINGS table
CREATE TABLE BOOKINGS (
    BOOKING_ID NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    NAME VARCHAR2(100),
    EMAIL VARCHAR2(100),
    PHONE VARCHAR2(20),
    NUM_TICKETS NUMBER,
    MOVIE_TITLE VARCHAR2(100),
    BOOKING_DATE DATE DEFAULT SYSDATE
);
